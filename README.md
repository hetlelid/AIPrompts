A collection of prompts to use in different AI/LLM tools like ChatGPT or as a skill in Dia or Comet browser.

# Setup
## Perplexity Comet browser
Enter a forward slash (**/**) in the input field > Create a shortcut. Add for example **/summarize** as *Shortcut name*. and the specific prompt as *Instructions*.
